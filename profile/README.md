# 🌱 BloomWatch

Newly funded startups and their open roles, found the day they raise. For recruiters, sellers, and job seekers who want to reach companies while the money is fresh.

- **Web:** https://bloomwatch.co
- **API:** read-only JSON for companies, jobs, and sync. Docs at https://bloomwatch.co/help/api, OpenAPI spec at https://bloomwatch.co/api/v1/openapi.json
- **CLI:** [bloomwatchco/cli](https://github.com/bloomwatchco/cli), one file and no dependencies

Try it with no key:

```bash
npx github:bloomwatchco/cli sample
```

Developers: https://bloomwatch.co/developers. Support: bloomwatchsupport@zeninfinity.com
